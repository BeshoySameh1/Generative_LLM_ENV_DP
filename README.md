# Product Assistant — RAG Chatbot

A chatbot that answers questions about your product PDFs using retrieval-augmented
generation (MiniLM for retrieval + Flan-T5-base for answer generation).

## Folder structure

```
rag-chatbot/
├── pdfs/                  <- put your product PDF files here
├── build_index.py         <- run once to build the vector index from your PDFs
├── app.py                 <- the Streamlit chatbot app
├── requirements.txt
├── product_index.faiss    <- generated by build_index.py (commit this)
├── chunks.pkl             <- generated by build_index.py (commit this)
└── README.md
```

## 1. Local setup

```bash
git clone <your-repo-url>
cd rag-chatbot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Add your PDFs

Drop your product PDF files into the `pdfs/` folder:

```
pdfs/
├── product_catalog.pdf
├── datasheet_x100.pdf
└── faq.pdf
```

## 3. Build the vector index

Run this once (and again any time you add/update PDFs):

```bash
python build_index.py
```

This creates `product_index.faiss` and `chunks.pkl` in the project root.
**Both files must be committed to your GitHub repo** — the deployed app
loads them directly and does not need the raw PDFs at runtime.

## 4. Test locally

```bash
streamlit run app.py
```

Opens at `http://localhost:8501`.

## 5. Push to GitHub

```bash
git add .
git commit -m "RAG chatbot with product PDFs"
git push
```

Make sure `product_index.faiss` and `chunks.pkl` are actually committed
(check they're not excluded by a `.gitignore`).

## 6. Deploy for free on Streamlit Community Cloud

1. Go to https://share.streamlit.io and sign in with GitHub.
2. Click **New app**.
3. Select your repo, branch, and `app.py` as the entry point.
4. Click **Deploy**.
5. You'll get a live URL like `https://yourname-rag-chatbot.streamlit.app`.

The free tier sleeps after inactivity and wakes automatically (~30-60s)
on the next visit — no payment info required.

## 7. (Optional) Custom domain

Streamlit Community Cloud doesn't support custom domains directly. To use
your own domain, host a simple static page (Vercel/Netlify, free) with an
iframe pointing at your Streamlit URL:

```html
<iframe src="https://yourname-rag-chatbot.streamlit.app"
        width="100%" height="700" frameborder="0"></iframe>
```

Then point your domain's DNS at Vercel/Netlify as usual.

## Updating the knowledge base later

Whenever you add/replace PDFs in `pdfs/`:

```bash
python build_index.py
git add product_index.faiss chunks.pkl
git commit -m "Update product index"
git push
```

Streamlit Cloud auto-redeploys on every push to the connected branch.

## Notes

- Flan-T5-base is small — answers are functional but basic. If quality feels
  weak, try swapping `GEN_MODEL_NAME` in `app.py` and `build_index.py`'s
  embed model for larger variants once you're comfortable with the pipeline.
- The embedding model is multilingual, but Flan-T5-base is English-centric,
  so answers to non-English questions may be weaker.
- The app tells the user when an answer isn't found in the documents rather
  than letting Flan-T5 guess from outside the PDFs.
